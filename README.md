# Portify ✦

### Create. Customize. Present.

Portify is a simple and elegant **Portfolio Creator** that helps users build a professional portfolio with a live preview and export it as a PDF.

## ✨ Features

- 📝 Easy portfolio editing
- 👀 Live portfolio preview
- 📷 Profile photo upload
- 💻 Skills and projects section
- 🎓 Education and certificates
- 🏆 Achievements section
- 🔗 GitHub and LinkedIn links
- 💾 Data saved using Local Storage
- 🎨 Multiple design options
- 🌙 Dark editor mode
- 📄 Print / PDF export
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Google Fonts
